# Sprint2

## Tecnología
Se utilizará **Angular** para el desarrollo de esta aplicación.

## Principios y Arquitectura
- **Principios SOLID**: Se aplicarán los principios SOLID para garantizar un código limpio, mantenible y escalable.
- **Arquitectura MVVM**: Se implementará la arquitectura Model-View-ViewModel para separar la lógica de negocio de la interfaz de usuario.
